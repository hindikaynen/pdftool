# PdfTool — PDF Overlay Engine

**PdfTool** — это утилита командной строки для добавления графических элементов (текст, фигуры, штрихкоды, изображения) на страницы PDF документов на основе JSON-спецификации.

Инструмент поддерживает две схемы размещения оверлеев:
- **Corner placement** — привязка к углам страницы
- **Text anchor placement** — привязка к текстовым меткам внутри документа

## Возможности

- ✅ **7 типов примитивов**: текст, прямоугольник, эллипс, линия, полилиния, изображение, штрихкод (QR/Code128)
- ✅ **Интеллектуальный поиск текста**: автоматический поиск текстовых меток и привязка к ним оверлеев
- ✅ **Поддержка ротации страниц**: корректное отображение на ротированных PDF (90°, 180°, 270°)
- ✅ **Диапазоны страниц**: гибкий синтаксис вида `"1-3,7-last,10"` для применения оверлеев к конкретным страницам
- ✅ **JSON-конфигурация**: легко читаемая и версионируемая спецификация оверлеев

## Требования

- **.NET 8.0+** (runtime или SDK)
- **PDF файл** (входящий документ)
- **JSON спецификация** (описание оверлеев)

## Быстрый старт (5 минут)

### Шаг 1: Создать JSON спецификацию

Создайте файл `overlays.json`:

```json
{
  "overlays": [
    {
      "name": "draft-watermark",
      "pages": "all",
      "placement": {
        "mode": "corner",
        "corner": "topRight",
        "offset": [20, 20]
      },
      "primitives": [
        {
          "type": "text",
          "at": [0, 0],
          "value": "DRAFT",
          "size": 48,
          "color": "#FF0000FF",
          "font": "Helvetica-Bold"
        }
      ]
    }
  ]
}
```

### Шаг 2: Валидировать спецификацию

```bash
pdftool validate --json overlays.json
# Output:
# JSON is valid.
# Overlays: 1
```

### Шаг 3: Применить к PDF

```bash
pdftool apply --in input.pdf --out output.pdf --json overlays.json
# Output:
# Plan built. Overlays: 1, totalPages: 42
```

**Результат:** файл `output.pdf` с красным текстом "DRAFT" в правом верхнем углу каждой страницы.

## Основные понятия

### Режимы размещения (placement mode)

**Corner Mode** — привязка к углам страницы:
- `topLeft`, `topRight`, `bottomLeft`, `bottomRight`, `topCenter`, `bottomCenter`
- Offset `[dx, dy]` — смещение внутрь от выбранного угла (в пунктах)
  - `dx` > 0 — смещение вправо (от левых углов) или влево (от правых углов)
  - `dy` > 0 — смещение вниз (от верхних углов) или вверх (от нижних углов)

**Text Anchor Mode** — привязка к текстовой метке:
- Ищет текст (например, `"[SIGN_HERE]"`) на странице
- Поддерживает `first`, `last`, `all` вхождения
- Offset `[right, down]` — смещение от найденной метки
  - `right` > 0 — смещение вправо от метки
  - `down` > 0 — смещение вниз от метки

### Диапазоны страниц (pages)

Синтаксис похож на `grep`:
- `"all"` — все страницы
- `"1"` — только 1-я страница
- `"1-3"` — страницы 1-3 включительно
- `"1,3,5"` — страницы 1, 3, 5
- `"1-3,7-last"` — страницы 1-3 и 7-последняя

### Примитивы (primitives)

Каждый примитив имеет тип (`type`), координаты и стиль:

| Тип | Использование | Ключевые поля |
|-----|---------------|---------------|
| `text` | Добавить текст | `at` или `rect`, `value`, `size`, `color`, `font` |
| `rect` | Рисовать прямоугольник | `rect` (x,y,w,h), `fill`, `stroke`, `strokeWidth` |
| `ellipse` | Рисовать эллипс | `rect` (x,y,w,h), `fill`, `stroke`, `strokeWidth` |
| `line` | Рисовать линию | `from`, `to`, `stroke`, `strokeWidth` |
| `polyline` | Рисовать полилинию | `points`, `stroke`, `strokeWidth` |
| `image` | Вставить изображение | `rect`, `base64` |
| `barcode` | Генерировать штрихкод | `kind` (qr/code128), `rect`, `value` |

### Координатная система

**Важно:** Все координаты примитивов используют **VIEW систему** (как видит пользователь):
- Origin (0, 0) находится в **левом верхнем углу** страницы
- X-ось растет слева направо (→)
- Y-ось растет сверху вниз (↓)

Это соответствует стандартным экранным координатам и делает работу с размещением интуитивной.

# Text — Добавление текста на PDF

## Обзор

Примитив `text` позволяет добавлять текстовую информацию на страницы PDF. Поддерживает два режима позиционирования:
- **Позиционирование в точке** (`at`) — текст начинается с заданной координаты
- **Позиционирование в прямоугольнике** (`rect`) — текст размещается в блоке с поддержкой выравнивания и переноса

## Структура JSON

```json
{
  "type": "text",
  "value": "Текст для вывода",
  "at": [x, y],              // ИЛИ
  "rect": [x, y, width, height],
  
  "size": 12,                // Размер шрифта в pt (опционально, default: 12)
  "font": "Helvetica",       // Имя шрифта (опционально, default: Helvetica)
  "color": "#000000FF",      // Цвет текста в hex (опционально, default: #000000FF)
  
  "wrap": true,              // Перенос строк (только с rect, опционально)
  "halign": "left",          // Горизонтальное выравнивание (только с rect)
  "valign": "top",           // Вертикальное выравнивание (только с rect)
}
```

## Параметры

### Обязательные

| Параметр | Тип | Описание |
|----------|-----|---------|
| `type` | string | Всегда `"text"` |
| `value` | string | Текст для вывода (не пустой) |
| `at` или `rect` | number[] | **Ровно одно** из них должно быть определено |

### Опциональные (стиль)

| Параметр | Тип | Default | Описание |
|----------|-----|---------|---------|
| `size` | number | 12 | Размер шрифта в пунктах (pt). Значение > 0 |
| `font` | string | "Helvetica" | Название шрифта (см. поддерживаемые ниже) |
| `color` | string | "#000000FF" | Цвет в формате hex (#RRGGBBAA) |

### Опциональные (позиционирование)

| Параметр | Тип | Область | Описание |
|----------|-----|---------|---------
| `wrap` | boolean | Только с `rect` | Включить перенос слов. Требует `rect` |
| `halign` | string | Только с `rect` | Горизонтальное выравнивание: `left`, `center`, `right` |
| `valign` | string | Только с `rect` | Вертикальное выравнивание: `top`, `middle`, `bottom` |

## Режимы позиционирования

### Режим 1: Позиционирование в точке (`at`)

Текст начинается с левого верхнего угла заданной точки.

```json
{
  "type": "text",
  "at": [50, 100],
  "value": "Hello World",
  "size": 14,
  "color": "#000000FF"
}
```

**Координаты:**
- `at: [x, y]` — массив из 2 чисел (x, y в пунктах)
- **x** — горизонтальная позиция от левого края (pt)
- **y** — вертикальная позиция от верхнего края (pt)

**Особенности:**
- Текст всегда выравнивается по левому краю
- Высота определяется размером шрифта (`size`)
- Параметры `wrap`, `halign`, `valign` **не допускаются**

**Пример:**

```json
{
  "name": "simple-text",
  "pages": "1",
  "placement": {
    "mode": "corner",
    "corner": "bottomLeft",
    "offset": [10, 10]
  },
  "primitives": [
    {
      "type": "text",
      "at": [0, 0],
      "value": "© 2024 Company Inc.",
      "size": 10,
      "color": "#666666FF",
      "font": "Helvetica"
    }
  ]
}
```

---

### Режим 2: Позиционирование в прямоугольнике (`rect`)

Текст размещается внутри прямоугольной области с поддержкой выравнивания и переноса строк.

```json
{
  "type": "text",
  "rect": [50, 100, 200, 80],
  "value": "Многострочный текст с переносом",
  "size": 12,
  "color": "#333333FF",
  "wrap": true,
  "halign": "center",
  "valign": "middle"
}
```

**Координаты:**
- `rect: [x, y, width, height]` — массив из 4 чисел
- **x, y** — левый верхний угол блока (pt)
- **width, height** — размер блока (pt)

**Особенности:**
- Текст может быть выравнен горизонтально и вертикально
- Поддерживается автоматический перенос строк (`wrap: true`)
- Текст обрезается, если не помещается в rect

**Пример с переносом:**

```json
{
  "type": "text",
  "rect": [10, 50, 180, 100],
  "value": "Это длинный текст который будет автоматически переноситься на новую строку если включена опция wrap",
  "size": 10,
  "color": "#000000FF",
  "wrap": true,
  "halign": "left",
  "valign": "top"
}
```

# Rect — Рисование прямоугольников

## Обзор

Примитив `rect` позволяет рисовать прямоугольники с поддержкой:
- **Заливки** (fill) — сплошной цвет фона
- **Обводки** (stroke) — контур прямоугольника
- **Скругленных углов** (cornerRadius) — для создания овальных углов
- **Прозрачности** — через alpha-канал в цветах

Прямоугольник часто используется как фон или рамка для текста, а также для создания визуальных элементов интерфейса.

## Структура JSON

```json
{
  "type": "rect",
  "rect": [x, y, width, height],
  
  "fill": "#FFFFFFFF",           // Цвет фона (опционально)
  "stroke": "#000000FF",         // Цвет контура (опционально)
  "strokeWidth": 2.0,            // Толщина линии (опционально, default: 1)
  "cornerRadius": 5.0            // Скругление углов (опционально, default: 0)
}
```

## Параметры

### Обязательные

| Параметр | Тип | Описание |
|----------|-----|---------
| `type` | string | Всегда `"rect"` |
| `rect` | number[] | Массив [x, y, width, height] в пунктах (pt) |

### Опциональные (стиль)

| Параметр | Тип | Default | Описание |
|----------|-----|---------|---------
| `fill` | string | null | Цвет заливки в hex формате (#RRGGBBAA) |
| `stroke` | string | null | Цвет контура в hex формате (#RRGGBBAA) |
| `strokeWidth` | number | 1 | Толщина линии контура (pt). Значение ≥ 0 |
| `cornerRadius` | number | 0 | Радиус скругления углов (pt). Значение ≥ 0 |

## Параметры rect

### Координаты и размеры

```json
{
  "type": "rect",
  "rect": [x, y, width, height]
}
```

| Компонент | Тип | Описание |
|-----------|-----|---------|
| **x** | number | Горизонтальная позиция левого края (pt) |
| **y** | number | Вертикальная позиция верхнего края (pt) |
| **width** | number | Ширина прямоугольника (pt). Должна быть ≥ 0 |
| **height** | number | Высота прямоугольника (pt). Должна быть ≥ 0 |

**Координатная система:**
- Origin (0, 0) находится в **левом верхнем углу** страницы (VIEW система)
- X-ось растет слева направо
- Y-ось растет сверху вниз (как на экране)

**Пример:**
```json
{
  "type": "rect",
  "rect": [50, 100, 200, 80]
  // x=50, y=100, width=200, height=80
  // Левый верхний угол в (50, 100), правый нижний в (250, 180)
}
```

## Цвета и форматы

### Формат hex (#RRGGBBAA)

Цвета задаются в формате `#RRGGBBAA`:
- **RR** — красный канал (00-FF)
- **GG** — зеленый канал (00-FF)
- **BB** — синий канал (00-FF)
- **AA** — альфа-канал, прозрачность (00=невидимо, FF=видимо)

| Цвет | Код | Описание |
|------|-----|---------|
| Черный (непрозрачный) | `#000000FF` | Полностью видимый черный |
| Белый (непрозрачный) | `#FFFFFFFF` | Полностью видимый белый |
| Красный (полупрозрачный) | `#FF000080` | Красный с 50% прозрачностью |
| Прозрачный | `#FFFFFF00` | Полностью невидимый (alpha=0) |

## Режимы рисования

### Режим 1: Только контур (stroke)

```json
{
  "type": "rect",
  "rect": [50, 100, 200, 80],
  "stroke": "#000000FF",
  "strokeWidth": 2
}
```

**Результат:** прямоугольник с черной линией, белым фоном (прозрачный).

**Использование:**
- Создание рамок вокруг текста
- Выделение областей
- Создание сетки/таблицы

### Режим 2: Только заливка (fill)

```json
{
  "type": "rect",
  "rect": [50, 100, 200, 80],
  "fill": "#FFFF00FF"
}
```

**Результат:** желтый прямоугольник без контура.

**Использование:**
- Фоновые цвета для текста
- Блоки с цветной заливкой
- Создание визуальных элементов

### Режим 3: Заливка + контур (fill + stroke)

```json
{
  "type": "rect",
  "rect": [50, 100, 200, 80],
  "fill": "#FFFFFFFF",
  "stroke": "#0000FFFF",
  "strokeWidth": 2
}
```

**Результат:** белый прямоугольник с синей границей.

**Использование:**
- Декоративные элементы
- Выделение важных областей
- Боксы с рамками

### Режим 4: Заливка с прозрачностью

```json
{
  "type": "rect",
  "rect": [50, 100, 200, 80],
  "fill": "#FF000080"  // Красный с 50% прозрачностью
}
```

**Результат:** полупрозрачный красный прямоугольник, видны объекты под ним.

**Использование:**
- Наложение цвета на существующее содержимое
- Создание эффекта watermark
- Выделение текста

## Скругленные углы (cornerRadius)

### Простой прямоугольник (0 radius)

```json
{
  "type": "rect",
  "rect": [50, 100, 200, 80],
  "fill": "#0000FFFF",
  "cornerRadius": 0  // Резкие углы
}
```

### Скругленные углы (5-10 pt)

```json
{
  "type": "rect",
  "rect": [50, 100, 200, 80],
  "fill": "#0000FFFF",
  "cornerRadius": 5
}
```

**Результат:** прямоугольник с мягко скругленными углами.

## Ограничения и валидация

### Правила валидации

| Правило | Ошибка | Пример |
|---------|--------|--------|
| `rect` должна быть массивом [x,y,w,h] | `rect.rect must be [x,y,w,h]` | ❌ `"rect": [10, 20]` |
| Ширина ≥ 0 | `rect.w/h must be >= 0` | ❌ `"rect": [10, 10, -50, 50]` |
| Высота ≥ 0 | `rect.w/h must be >= 0` | ❌ `"rect": [10, 10, 50, -50]` |
| strokeWidth ≥ 0 | `rect.strokeWidth must be >= 0` | ❌ `"strokeWidth": -2` |
| cornerRadius ≥ 0 | `rect.cornerRadius must be >= 0` | ❌ `"cornerRadius": -5` |
| Цвет в hex формате | Ошибка парсинга | ❌ `"fill": "red"` (должно `"#FF0000FF"`) |

# Ellipse — Рисование эллипсов и окружностей

## Обзор

Примитив `ellipse` позволяет рисовать эллипсы (овалы) и окружности (круги) с поддержкой:
- **Заливки** (fill) — сплошной цвет внутри
- **Обводки** (stroke) — контур эллипса
- **Прозрачности** — через alpha-канал в цветах

Эллипс определяется прямоугольником-ограничением (bounding box), внутри которого вписана форма. Это один из самых простых геометрических примитивов.

## Структура JSON

```json
{
  "type": "ellipse",
  "rect": [x, y, width, height],
  
  "fill": "#FFFFFFFF",           // Цвет заливки (опционально)
  "stroke": "#000000FF",         // Цвет контура (опционально)
  "strokeWidth": 2.0             // Толщина линии (опционально, default: 1)
}
```

## Параметры

### Обязательные

| Параметр | Тип | Описание |
|----------|-----|---------|
| `type` | string | Всегда `"ellipse"` |
| `rect` | number[] | Массив [x, y, width, height] — bounding box эллипса (pt) |

### Опциональные (стиль)

| Параметр | Тип | Default | Описание |
|----------|-----|---------|---------
| `fill` | string | null | Цвет заливки в hex формате (#RRGGBBAA) |
| `stroke` | string | null | Цвет контура в hex формате (#RRGGBBAA) |
| `strokeWidth` | number | 1 | Толщина линии контура (pt). Значение ≥ 0 |

## Параметры rect (Bounding Box)

### Что такое bounding box?

Эллипс вписан в прямоугольник (bounding box):

```
rect = [x, y, width, height]

     (x, y) ───────────────────── (x+width, y)
        │           ЭЛЛИПС          │
        │        вписан сюда        │
        │                           │
        │                           │
     (x, y+height) ──────────────────
```

### Координаты и размеры

| Компонент | Тип | Описание |
|-----------|-----|---------|
| **x** | number | Горизонтальная позиция левого края bounding box (pt) |
| **y** | number | Вертикальная позиция верхнего края bounding box (pt) |
| **width** | number | Ширина bounding box (pt). Должна быть ≥ 0 |
| **height** | number | Высота bounding box (pt). Должна быть ≥ 0 |

**Координатная система:**
- Origin (0, 0) находится в **левом верхнем углу** страницы (VIEW система)
- X-ось растет слева направо
- Y-ось растет сверху вниз (как на экране)

### Примеры

**Окружность (круг — width == height):**
```json
{
  "type": "ellipse",
  "rect": [50, 100, 100, 100]  // width=100, height=100 → окружность
}
```

**Горизонтальный эллипс (width > height):**
```json
{
  "type": "ellipse",
  "rect": [50, 100, 200, 80]   // width=200, height=80 → овал
}
```

**Вертикальный эллипс (width < height):**
```json
{
  "type": "ellipse",
  "rect": [50, 100, 80, 200]   // width=80, height=200 → вертикальный овал
}
```

# Line — Рисование прямых линий

## Обзор

Примитив `line` позволяет рисовать прямые линии между двумя точками с поддержкой:
- **Цвета линии** (stroke) — цвет обводки
- **Толщины линии** (strokeWidth) — ширина в пунктах
- **Прозрачности** — через alpha-канал в цвете

Линии используются для разделения областей, подчеркивания текста, создания границ и декоративных элементов.

## Структура JSON

```json
{
  "type": "line",
  "from": [x1, y1],
  "to": [x2, y2],
  
  "stroke": "#000000FF",        // Цвет линии (опционально, default: #000000FF)
  "strokeWidth": 1.0            // Толщина линии в pt (опционально, default: 1)
}
```

## Параметры

### Обязательные

| Параметр | Тип | Описание |
|----------|-----|---------|
| `type` | string | Всегда `"line"` |
| `from` | number[] | Массив [x1, y1] — начальная точка (pt) |
| `to` | number[] | Массив [x2, y2] — конечная точка (pt) |

### Опциональные (стиль)

| Параметр | Тип | Default | Описание |
|----------|-----|---------|---------
| `stroke` | string | "#000000FF" | Цвет линии в hex формате (#RRGGBBAA) |
| `strokeWidth` | number | 1 | Толщина линии (pt). Значение ≥ 0 |

## Координаты

### From и To (начало и конец)

```json
{
  "type": "line",
  "from": [x1, y1],
  "to": [x2, y2]
}
```

| Компонент | Тип | Описание |
|-----------|-----|---------|
| **x1, y1** | number | Координаты начальной точки линии (pt) |
| **x2, y2** | number | Координаты конечной точки линии (pt) |

**Координатная система:**
- Origin (0, 0) находится в **левом верхнем углу** страницы
- X-ось растет слева направо
- Y-ось растет сверху вниз (как на экране)

**Примеры:**

```json
// Горизонтальная линия (слева направо)
{
  "type": "line",
  "from": [0, 100],
  "to": [200, 100]
}

// Вертикальная линия (сверху вниз)
{
  "type": "line",
  "from": [100, 0],
  "to": [100, 200]
}

// Диагональная линия (слева-сверху в право-вниз)
{
  "type": "line",
  "from": [0, 0],
  "to": [200, 200]
}
```

# Polyline — Рисование полилиний

## Обзор

Примитив `polyline` позволяет рисовать полилинии — последовательности соединенных прямых линий между несколькими точками с поддержкой:
- **Цвета линии** (stroke) — цвет обводки
- **Толщины линии** (strokeWidth) — ширина в пунктах
- **Прозрачности** — через alpha-канал в цвете

Полилинии используются для рисования сложных контуров, ломаных линий, графиков, пользовательских форм и декоративных элементов.

## Структура JSON

```json
{
  "type": "polyline",
  "points": [
    [x1, y1],
    [x2, y2],
    [x3, y3],
    ...
  ],
  
  "stroke": "#000000FF",        // Цвет линии (опционально, default: #000000FF)
  "strokeWidth": 1.0            // Толщина линии в pt (опционально, default: 1)
}
```

## Параметры

### Обязательные

| Параметр | Тип | Описание |
|----------|-----|---------|
| `type` | string | Всегда `"polyline"` |
| `points` | number[][] | Массив точек [[x1,y1], [x2,y2], ...]. Минимум 2 точки |

### Опциональные (стиль)

| Параметр | Тип | Default | Описание |
|----------|-----|---------|---------
| `stroke` | string | "#000000FF" | Цвет линии в hex формате (#RRGGBBAA) |
| `strokeWidth` | number | 1 | Толщина линии (pt). Значение ≥ 0 |

## Параметр Points (Точки)

### Структура points

```json
{
  "type": "polyline",
  "points": [
    [x1, y1],    // Первая точка
    [x2, y2],    // Вторая точка
    [x3, y3],    // Третья точка
    ...          // И так далее
  ]
}
```

| Компонент | Тип | Описание |
|-----------|-----|---------|
| **points** | number[][] | Двумерный массив координат |
| **[x, y]** | number[] | Каждая точка — массив из двух чисел |
| **Минимум** | 2 | Необходимо минимум 2 точки для линии |

**Координатная система:**
- Origin (0, 0) находится в **левом верхнем углу** страницы (VIEW система)
- X-ось растет слева направо
- Y-ось растет сверху вниз (как на экране)

### Примеры точек

**Простая ломаная линия (3 точки):**
```json
{
  "type": "polyline",
  "points": [
    [0, 0],
    [50, 50],
    [100, 0]
  ]
}
// Результат: линия вниз-вправо, потом вверх-вправо (V-образная перевернутая)
```

**Зигзаг (5 точек):**
```json
{
  "type": "polyline",
  "points": [
    [0, 0],
    [25, 25],
    [50, 0],
    [75, 25],
    [100, 0]
  ]
}
// Результат: волнистая линия
```

**Сложная форма (6 точек):**
```json
{
  "type": "polyline",
  "points": [
    [0, 0],
    [50, 0],
    [75, 25],
    [50, 50],
    [25, 25],
    [0, 0]
  ]
}
// Результат: пятиугольник (незамкнутый)
```

# Barcode — Генерирование штрихкодов и QR-кодов

## Обзор

Примитив `barcode` позволяет автоматически генерировать и рисовать штрихкоды с поддержкой:
- **QR-кодов** — двумерные коды для URL, контактов, платежей
- **Code128** — одномерные штрихкоды для товаров, посылок, документов
- **Опций кодирования** — уровни коррекции ошибок, форматирование
- **Стилизации** — цвет, фон, граница, масштабирование

Штрихкоды используются для отслеживания товаров, платежей, ссылок и идентификации документов.

## Структура JSON

```json
{
  "type": "barcode",
  "kind": "qr",              // или "code128"
  "rect": [x, y, width, height],
  "value": "https://example.com",
  
  "color": "#000000FF",        // Цвет кода (опционально, default: #000000FF)
  "fill": "#FFFFFFFF",         // Цвет фона (опционально)
  "stroke": "#CCCCCCFF",       // Цвет контура (опционально)
  "strokeWidth": 1,            // Толщина контура (опционально)
  "options": {                 // Опции кодирования (опционально)
    "ecLevel": "M"             // Для QR: L, M, Q, H
  }
}
```

## Параметры

### Обязательные

| Параметр | Тип | Описание |
|----------|-----|---------|
| `type` | string | Всегда `"barcode"` |
| `kind` | string | Тип штрихкода: `"qr"` или `"code128"` |
| `rect` | number[] | Массив [x, y, width, height] — размер и позиция (pt) |
| `value` | string | Данные для кодирования (URL, текст, число) |

### Опциональные (стиль)

| Параметр | Тип | Default | Описание |
|----------|-----|---------|---------
| `color` | string | "#000000FF" | Цвет штрихкода в hex формате (#RRGGBBAA) |
| `fill` | string | null | Цвет фона (#RRGGBBAA) |
| `stroke` | string | null | Цвет контура (#RRGGBBAA) |
| `strokeWidth` | number | null | Толщина контура (pt) |
| `options` | object | null | Опции кодирования (см. ниже) |

### Опциональные (для QR)

| Параметр | Тип | Значения | Описание |
|----------|-----|----------|---------
| `options.ecLevel` | string | "L", "M", "Q", "H" | Уровень коррекции ошибок |

### Опциональные (для Code128)

| Параметр | Тип | Значения | Описание |
|----------|-----|----------|---------
| `options.showText` | boolean | true, false | Показывать ли текст под кодом |
